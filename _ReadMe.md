# Run

Instructions for running the project:

1. **Install Node.js and npm**

   Download and install Node.js (npm comes bundled with it) from the official website: [https://nodejs.org/](https://nodejs.org/).

   Verify that npm is installed:

   ```bash
   npm -v
   ```

2. **Install Node.js version 20**

   It is recommended to use Node.js v20. The easiest way is via [nvm](https://github.com/nvm-sh/nvm):

   ```bash
   nvm install 20
   nvm use 20
   ```

   Verify the current version:

   ```bash
   node -v
   ```

3. **Install project dependencies**

   In the project root, run:

   ```bash
   npm install
   ```

4. **Run the project**

   ```bash
   npm run dev
   ```

   Once started, Vite will print a local URL in the terminal (usually [http://localhost:5173](http://localhost:5173)) — open it in your browser.
